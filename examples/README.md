# Sample Data & Demo Files

This directory is reserved for **anonymized sample newspaper PDFs** and **demo screening/coding CSVs** so researchers and new users can test the MMIWG Archival Coding Suite end-to-end without needing private archival files.

## Planned Files

* `sample_article.pdf` — Anonymized sample newspaper article PDF (for testing **OCRProcessor**, **Highlighter**, and **SingleCoder**).
* `sample_screening_list.csv` — Demo screening/coding CSV matching the expected column layout (for testing **DriveDownloader** and **BatchCoder**).

*(Note: Files placed in `examples/` are explicitly tracked by Git via `.gitignore` exceptions.)*
